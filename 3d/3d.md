# StarKeeper One - 3D Version

A full 3D space simulation version of the 2D game.

## Implementation Status: COMPLETE ✓

### Features Implemented

- **3D Space Environment**: Full 3D world with no edge wrapping
- **Camera System**: 3rd person perspective locked to player ship
- **WebGL Rendering**: Custom renderer with Gouraud shading on castle ring faces
- **3D Models**: Hand-constructed models converted from 2D versions
  - Player ship (triangular with volume)
  - Castle rings (3D extruded segments with faces)
  - Central hexagon
  - Cannon (3D articulated)
  - Sparks/projectiles
  - Explosions (3D debris)

### Controls

- **W/A/S/D**: Forward/Rotate Left/Reverse/Rotate Right
- **Mouse**: Aim ship (pitch and yaw) - click canvas to capture pointer
- **Shift+A/D or Q/E**: Strafe left/right
- **Space**: Fire forward torpedo
- **R or F**: Drop aft space mine
- **Enter**: Start game / Continue to next round

### Architecture

- **Encapsulated Systems**: Player has ship object, castle has cannon, each system self-contained
- **No Code Sharing**: All code copied from 2D version and adapted for 3D
- **Vertical Movement Limited**: Player Y position clamped to prevent going too far above/below castle
- **Coordinate System**: Standard 3D coords (X/Y/Z) with castle at origin

### Technical Details

- **Renderer**: WebGL with custom shaders
  - Line rendering for wireframes
  - Gouraud shading for solid faces (lighting calculated per-vertex)
  - Depth testing and alpha blending
- **Math**: 3D vector and matrix utilities (vec3, mat4, quat)
- **Physics**: Full 3D velocity/position for all entities
- **AI**: Enemy behavior adapted for 3D space (spawning, lingering, chasing, flocking)
- **Collisions**: 3D distance checks for all collision types

### Differences from 2D Version

1. **No autopilot** (as specified)
2. **Mouse aiming** instead of keyboard rotation only
3. **3D spatial movement** with vertical limits
4. **Camera follows player** in 3rd person
5. **Gouraud shading** on castle ring faces
6. **No screen wrapping** - open 3D space
7. **3D enemy AI** with full spatial flocking

### To Run

Open `3d/index.html` in a web browser that supports WebGL.
Click on the canvas to capture mouse for aiming.
Press Enter to start.
